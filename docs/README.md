## Mantenimiento

Actualizar el documento dueño del tema. Registrar decisiones duraderas en un ADR y resultados de implementación brevemente en el changelog. No crear un documento por cada ronda, sesión o respuesta de un asesor. No duplicar especificaciones ni manuales en AGENTS: [AGENTS.md](../AGENTS.md) contiene reglas operativas y enlaces.

Distinguir siempre decisión aprobada, propuesta, implementación local y validación externa. Una revisión de agentes o prueba técnica no equivale a aprobación del cliente ni de una institución. Los ADRs aceptados y los paquetes enviados para revisión son snapshots históricos, no una lista de instrucciones actuales.
