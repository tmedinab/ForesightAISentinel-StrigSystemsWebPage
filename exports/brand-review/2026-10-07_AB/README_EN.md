# Strig Systems / Athene — A and B review package

Snapshot: 2026-10-07. Prepared for independent professional evaluation. No production identity is adopted by this package.

Suggested order:

1. Open `boards/03_AB_comparison.svg` for initial impressions.
2. Inspect `boards/01_option_A.svg`, `02_option_B.svg`, `04_native_sizes.svg` and `05_contexts_AB.svg`.
3. Read `DESIGN_BRIEF_EN.md` or `DESIGN_BRIEF_EN.html`.
4. Inspect `vectors/A/` and `vectors/B/` in your vector editor. Optionally use `REVIEW_RESPONSE_TEMPLATE_EN.md`.

All visible board labels and SVG accessibility descriptions are in English. Board text and wordmarks are paths for reliable import. SVGs have no external font, raster or script dependency. PNGs in `previews/` are convenience proofs, not editable masters.

Each route contains Strig and Athene symbols and horizontal lockups in fixed ink (`#101820`) and white (`#ffffff`). Files are transparent. White files can appear blank on a white canvas; use a dark background. Paths remain editable; outlined type is editable as shapes, not live text. Install the included Space Grotesk font if reconstructing live lettering. Follow its included OFL license.

`source/geometry_EN.json` records exact paths, transforms, construction parameters and repository origins. `MANIFEST.json` records package file hashes. `QA_REPORT.json` records export checks after rendering. These support traceability, not legal clearance or aesthetic approval.

A contains H1 and the preferred open Athene with prolonged returns/balanced composition. B contains B3's supported longitudinal turns and the unchanged R15 profile. Older B solid/diagonal trials and option C are outside this requested package. No new design iteration was introduced by exporting.

The client will send this package personally; it has not been sent or published by the assistant. For the review scope, business context, caveats and specific open questions, see the briefing.
